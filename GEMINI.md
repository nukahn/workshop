# Project Instructions

## Development Workflow

Every time you modify the codebase, you **MUST** follow these steps:

1.  **Version Bump:** Update the build version string in `index.html`.
    *   Format: `Build: YYYY-MM-DD-vN` (e.g., `2026-05-19-v9`).
    *   Increment the version number (`vN`) for each distinct change set.
2.  **GitHub Sync:** Commit and push the changes to the remote repository.
    *   Use the `origin-fork` remote if `origin` is restricted.
    *   Provide a clear, descriptive commit message.

## UI/UX Standards

*   Maintain the established color palette and spacing.
*   Ensure the operator's bar (admin-bar) remains functional and accessible only to admins.
